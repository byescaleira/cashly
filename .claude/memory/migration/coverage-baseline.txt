Blocker discovered during Wave 0
--------------------------------
`swift test` from CLI fails on CashlyResource module:

  CashlyResourceFile.swift:18:22  cannot find type 'Data' in scope
  CashlyResourceImage.swift:17:26 cannot find type 'ImageResource' in scope

Root cause:
1. Sources `import RyzeFoundation` only. Foundation/SwiftUI not transitively re-exported.
2. `ImageResource` requires .xcassets bundled in package; current package only `.copy`s JSON mocks. App's Assets.xcassets lives in app target.

Why app builds: Xcode adds implicit Foundation/SwiftUI imports for app/widget targets and processes app-target Assets.xcassets. SPM CLI does not.

Resolution path: xcodebuild-based CI (this Wave 0) sidesteps the issue. True fix tracked as new gap (G027) for Wave 1 — add explicit imports + relocate ImageResource lookup to a target that has the asset catalog OR add an asset catalog to CashlyResource.
